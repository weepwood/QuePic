# 上传治理与远程缩略图

## 上传额度

QuePic 对每个本地账号使用滚动一小时窗口：

- 保守上限：140 次远程上传尝试/小时；
- 最小间隔：25 秒；
- 失败的远程请求也计入本地额度；
- SHA-256 命中的重复图片在远程请求前返回历史链接，不消耗额度；
- 单一后端上传闸门防止多个前端入口并发绕过限速。

该限制用于在语雀约 150 张/小时的经验阈值下保留余量，不代表语雀官方承诺的固定配额。

## 缓存恢复顺序

清理本地缓存后，进入可视区域的图片按以下顺序恢复：

1. 检查本地缓存；
2. 对已保存的远程 URL 发起受控缩略图请求；
3. 使用已保存的语雀会话回源；
4. 在用户显式开启时使用 WordPress CDN 兼容兜底。

远程 URL 请求只允许 HTTPS 的 `yuque.com` 和 `nlark.com` 域名，禁止重定向，最多两路并发，并保持全局请求间隔。

## 分类

图片分类存储于本地 SQLite 的独立关联表中，升级时不会改写已有 `assets` 表。历史图片默认显示为“未分类”；文件夹转文档上传的图片自动使用文件夹名称作为分类。

## OpenAPI Token

Token 按 QuePic 账号保存到操作系统密钥库，不写入 localStorage、SQLite、日志或前端配置。文件夹转文档创建文档时由 Rust 后端读取。
