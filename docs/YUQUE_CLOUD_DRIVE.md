# 语雀云盘实现说明

## 定位

语雀云盘采用“语雀保存原始附件，本地保存管理索引”的方式：

- 原始文件上传到语雀网页附件接口；
- 本地 SQLite 保存文件名、SHA-256、大小、MIME、文件夹、标签、来源账号和语雀地址；
- 下载时使用来源账号的语雀会话回源原始文件；
- 删除默认只删除本地索引，不删除语雀服务器上的附件。

它不是多端自动同步盘，也不会把语雀当成具有稳定 SLA 的对象存储。语雀网页附件接口属于非公开接口，接口参数、返回结构、风控和附件限制可能变化。

## 上传协议

上传由 Rust 后端执行：

1. 使用系统文件选择器取得真实本地路径；
2. 流式计算 SHA-256，避免将整个文件载入 WebView；
3. 使用 `multipart/form-data`，字段名为 `file`；
4. 请求语雀网页附件上传端点，并携带当前账号 Cookie 与 `yuque_ctoken`；
5. 有已验证文档上下文时关联该文档，否则使用无文档上下文附件上传；
6. 优先保存响应中的原始下载地址，其次才使用通用或预览地址；
7. 上传成功后写入本地 SQLite 索引。

客户端内置的扩展名清单只用于提前提示常见 Office、WPS、PDF、文本、图片、设计、思维导图、压缩包、音频和视频格式。实际可上传格式、单文件大小、账号权限和频率限制始终以语雀服务端响应为准；无法识别的格式建议先压缩为 ZIP。

## 下载与安全边界

- 只接受 HTTPS 的语雀和 Nlark 域名；
- 禁止网络客户端自动跟随重定向；
- 每次重定向都重新校验目标域名；
- Cookie 只发送给语雀域名，不发送给 Nlark CDN；
- 检测到 HTML 登录页时拒绝保存，避免把登录页面误当作原始附件；
- 使用同目录临时文件下载，成功后再提交到用户选择的位置；
- 当前设置 1 GB 的本地上传与下载保护上限，该值不是语雀官方额度承诺。

## 本地数据

主要数据表：

- `drive_files`：附件主体索引；
- `drive_folders`：本地文件夹；
- `drive_file_tags`：多标签关系。

同一来源账号下按 SHA-256 去重。备份选择包含本地图库索引时，云盘索引也会随数据库快照一并备份；Cookie 和 Token 不进入数据库或备份。

## 人工冒烟测试

由于上传依赖真实语雀账号、Cookie、会员状态和当前网页接口，上线前应使用测试账号完成以下检查：

1. 分别上传 PDF、DOCX、XLSX、PPTX、ZIP、图片和小型视频；
2. 确认返回地址可下载原始字节，文件哈希与本地源文件一致；
3. 测试主账号文档上下文上传和子账号无文档上下文上传；
4. 退出或使 Cookie 失效，确认下载显示重新登录提示；
5. 测试同文件重复上传、文件夹与标签修改、删除本地索引；
6. 测试包含中文、空格和长文件名的附件；
7. 检查上传日志中不包含完整本地路径、Cookie 或 Token。
