# 语雀云盘实现说明

## 定位

语雀云盘采用“语雀保存原始附件，本地保存管理索引”的方式：

- 原始文件上传到语雀网页图片或附件接口；
- 本地 SQLite 保存文件名、SHA-256、大小、MIME、文件夹、标签、来源账号和语雀地址；
- 下载时使用来源账号的语雀会话回源原始文件；
- 删除默认只删除本地索引，不删除语雀服务器上的附件。

它不是多端自动同步盘，也不会把语雀当成具有稳定 SLA 的对象存储。语雀网页上传接口属于非公开接口，接口参数、返回结构、风控和附件限制可能变化。

## 上传协议

上传由 Rust 后端执行，并要求账号已经验证目标语雀文档 URL，取得数字文档 ID 与文档 Referer。

### 图片

1. 使用系统文件选择器取得真实本地路径；
2. 根据 MIME 判断为图片；
3. 直接请求 `POST /api/upload/attach`；
4. query 使用 `attachable_type=Doc`、`attachable_id=<文档 ID>`、`type=image`、`ocr=off` 和 `ctoken`；
5. multipart 中只有字段名为 `file` 的文件本体；
6. 保存响应中的图片或附件 URL。

### 普通附件与 ZIP

1. 流式计算文件 MD5、大小和 MIME；
2. 请求 `POST /api/upload/upload_by_digset`，提交 `md5`、`filesize`、`filename`、`filetype` 和 `ctoken`；
3. 若响应包含 `symlink: 1`，直接复用返回的 `url`，不再上传文件本体；
4. 未命中秒传时，请求 `POST /api/upload/attach`；
5. query 使用 `attachable_type=Doc`、`attachable_id=<文档 ID>`、`type=attachment` 和 `ctoken`；
6. multipart 中只有字段名为 `file` 的文件本体；
7. 上传成功后写入本地 SQLite 索引。

上传请求携带与网页一致的 Cookie、Origin、Referer、User-Agent、Accept 和 `X-Requested-With`。网络错误或服务端 5xx 最多自动重试两次，退避时间为 0.5 秒和 1 秒。

客户端内置的扩展名清单只用于提前提示常见 Office、WPS、PDF、文本、图片、设计、思维导图、压缩包、音频和视频格式。实际可上传格式、单文件大小、账号权限和频率限制始终以语雀服务端响应为准；无法识别的格式建议先压缩为 ZIP。

## 下载与安全边界

- 只接受 HTTPS 的语雀和 Nlark 域名；
- 禁止网络客户端自动跟随重定向；
- 每次重定向都重新校验目标域名；
- Cookie 只发送给语雀域名，不发送给 Nlark CDN；
- 检测到 HTML 登录页时拒绝保存，避免把登录页面误当作原始附件；
- 使用同目录临时文件下载，成功后再提交到用户选择的位置；
- 当前设置 1 GB 的本地上传与下载保护上限，该值不是语雀官方额度承诺。

## 本地数据

主要数据表：

- `drive_files`：附件主体索引；
- `drive_folders`：本地文件夹；
- `drive_file_tags`：多标签关系。

同一来源账号下按 SHA-256 去重。语雀附件秒传则使用网页接口要求的 MD5。备份选择包含本地图库索引时，云盘索引也会随数据库快照一并备份；Cookie 和 Token 不进入数据库或备份。

## 自动检查

提交合并前应通过仓库现有 CI：

- React 生产构建；
- 平台图标生成；
- Rust `fmt`、Clippy、`cargo check` 与库单元测试；
- 上传 URL、图片/附件分类、MD5 标准向量和秒传响应解析单元测试。

自动检查只能验证代码与静态协议边界，不能代替带真实语雀会话的附件上传与下载测试。

## 人工冒烟测试

由于上传依赖真实语雀账号、Cookie、目标文档权限和当前网页接口，上线前应使用测试账号完成以下检查：

1. 上传普通 JPG/PNG，确认走图片模式并返回可访问地址；
2. 上传新的 ZIP，确认先秒传检测，再完成 multipart 文件上传；
3. 重复上传同一 ZIP，确认命中 `symlink` 后直接复用地址；
4. 下载 ZIP 并确认文件哈希与本地源文件一致；
5. 使用无文档上下文或无权限账号上传，确认显示明确配置或权限错误；
6. 退出或使 Cookie 失效，确认下载显示重新登录提示；
7. 测试包含中文、空格和长文件名的附件；
8. 检查上传日志中不包含完整本地路径、Cookie 或 Token。
